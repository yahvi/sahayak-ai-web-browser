Engineered for Accuracy & Safety

Every capability is purpose-built to eliminate hallucination, enforce strict privacy, and keep you in total control.

📄

Grounded Article Summaries

Uses Mozilla Readability to strip ads and sidebars, extracting clean article text. Gemini summarizes strictly from page text and explicitly tells you when information is absent.

🎬

Native YouTube Understanding

Direct integration with Gemini 2.5 Flash for public YouTube videos. Extracts key takeaways and interactive chapter timestamps — click any timestamp to seek the video tab.

🇮🇳

Bilingual English & Hinglish

Instant one-click language toggle in the header. Explains complex technical documentation in natural Hinglish for effortless comprehension.

🛡️

Denylist Primacy Security

Banking, payments, checkouts, and medical portals are automatically classified as sensitive. Extraction, screen capture, and agent actions are completely blocked on sensitive pages.

🔒

Protected Field Barriers

Password, OTP/TOTP, and Credit Card fields are strictly blocked in code. The agent is mathematically prevented from typing into any protected security field.

🤖

Human-in-the-Loop Agent

Proposes exactly one verified DOM action at a time with rationale. Consequential actions (Submit, Pay, Send) require double confirmation before DOM execution.

Quick Installation (Under 2 Minutes)

Works on Google Chrome, Microsoft Edge, Brave, and other Chromium-based browsers.

1

Download or Build the Extension

Download the pre-packaged sahayak-extension.zip from Releases and extract it, or clone and build from source:

git clone https://github.com/sahayak-ai/sahayak.git cd sahayak npm install npm run build
2

Load Unpacked in Your Browser

Open chrome://extensions or edge://extensions in your URL bar. Enable Developer mode in the top-right corner, click Load unpacked, and select the dist/ folder.

3

Enter Your Gemini API Key

Click the Sahayak extension icon to open the side panel. Head to the Settings tab and paste your free Google AI Studio Gemini API Key. (Keys are stored only inside your browser's private local storage).

4

Test on Local Practice Errands

Sahayak includes built-in practice pages designed to test the agent loop safely on your own machine:

npm run serve:practice

Navigate to http://127.0.0.1:3000/form.html and watch Sahayak propose and fill form steps with your approval!
